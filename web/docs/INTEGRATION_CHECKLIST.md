사용한 수행값은 저장 검증용 입력이다. 대상 서비스의 실제 시험 통과나 AI 정확도 평가가 아니다.

실행:

```bash
npm ci
npm run dev -- --host 127.0.0.1
npm run build
npm run lint
```

VITE_API_URL(기본 http://127.0.0.1:8000/api/v2)과 백엔드 CORS를 맞춘다. API 키를 브라우저 환경변수에 넣지 않는다.

남은 범위: 실제 모델 연결 및 자동 API 작업 실행, 장시간 Job 진행/새로고침 복원, 운영 인증. PDF 뷰어 번들 크기 경고는 후속 성능 개선 대상이다. 기존 모델 결과의 전체 재생은 파이프라인 DB/스냅샷 인계 후 검증한다.
