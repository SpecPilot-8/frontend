# SpecPilot

```
AI 기반 요구사항-코드 검증 및 테스트 사양서 자동 생성 플랫폼
```

## 프로젝트 소개

SpecPilot은 소프트웨어 개발 과정에서 기획서(요구사항)에 정의된 기능이 실제 소스코드에 정확하게 구현되었는지를 자동으로 확인하고 검증하기 위해 개발된 시스템입니다.

기존의 개발 및 QA 과정에서는 요구사항과 코드를 일일이 대조하고 테스트 사양서를 별도로 작성해야 하므로 많은 시간이 소요되었습니다. SpecPilot은 LLM을 활용하여 기획서와 소스코드를 분석하고 판정 결과를 시각적으로 제공하여, 개발자의 코드 리뷰 효율을 높이고 QA 업무의 생산성을 향상시키는 것을 목표로 합니다.

본 저장소는 SpecPilot 프로젝트의 프론트엔드를 담당합니다.

## 프로젝트 목표 및 기대 효과

**요구사항 대비 구현 상태 자동 검증**

* 기획서에서 구현해야 할 항목을 추출하고 실제 소스코드와 대조합니다.
* 요구사항별로 구현, 부분구현, 불일치, 미구현 후보 등의 상태를 명확히 판정하여 신속한 피드백을 제공합니다.

**코드 리뷰 효율화**

* 각 요구사항과 관련된 파일, 함수, 판정 근거를 직접 연결하여 시각화합니다.
* 개발자가 관련 코드를 즉시 확인하고 리뷰할 수 있도록 화면 도달 범위와 호출 흐름을 제공합니다.

**테스트 사양서 자동 생성**

* 요구사항과 코드 검증 결과를 바탕으로 정상, 오류, 경계 조건 등의 테스트 케이스 초안을 자동 생성합니다.
* 산출된 테스트 케이스를 기반으로 실제 수행 결과를 기록하고 테스트 사양서(Excel) 형태로 출력하여 QA 과정을 단축시킵니다.

## 주요 기능

**문서 및 프로젝트 설정**

* 기획서(PDF) 및 소스코드(ZIP 파일 또는 로컬 경로) 업로드
* 분석 대상 기술 스택 지정 및 서버 LLM 모델 연결 상태 점검

**명세 분석**

* 기획서 구조 파싱 및 화면/표 인식 (PDF 뷰어 연동)
* 주제, 소주제, 요구사항, 원자 수락조건 자동 추출
* 추출된 명세 내용 수동 편집 및 검토 확정

**검증 결과 모니터링**

* 요구사항별 코드 구현 상태 추적표 및 통계 대시보드
* 정적 호출 흐름 노드 시각화
* 가변 코드 근거 하이라이팅 및 AI 판정 사유 제공

**테스트 사양서 관리**

* 검증 완료 항목 대상 테스트 시나리오 및 예측 결과 도출
* 테스트 절차 편집 및 실제 수행 결과(통과/실패/보류) 수동 기록
* 템플릿 기반 테스트 사양서 엑셀(XLSX) 다운로드

## 프로젝트 구조

```
frontend/
├── extension/             # VS Code 익스텐션 환경
│   ├── src/extension.ts   # Webview 패널 생성 및 빌드된 웹앱 마운트
│   └── package.json       # 익스텐션 의존성 및 명령어 설정
└── web/                   # React 기반 웹 애플리케이션
    ├── src/
    │   ├── components/    # 공통 UI 컴포넌트
    │   ├── contexts/      # 상태 관리를 위한 Context API
    │   ├── hooks/         # Custom Hooks
    │   ├── services/      # 백엔드 API 통신
    │   ├── styles/        # 공통 스타일 및 디자인 시스템
    │   ├── types/         # API 응답 및 공통 타입 정의
    │   └── views/         # 4단계 워크스페이스 메인 화면
    └── package.json       # 웹앱 의존성 및 Vite 빌드 설정
```

## 실행 방법

### 실행 전 참고사항

SpecPilot UI 애플리케이션은 단독으로 모든 기능을 수행할 수 없습니다. AI 자동 분석, 코드 인덱싱 및 검증, 파일 저장 등을 위해 반드시 SpecPilot 백엔드 서버가 정상적으로 실행되어 있어야 합니다.

`web/.env.local` 파일을 생성하여 백엔드 API 주소를 설정하십시오. (설정하지 않을 경우 기본값 `http://127.0.0.1:8000/api/v2`가 사용됩니다.)

```
VITE_API_URL=http://127.0.0.1:8000/api/v2
```

본 프로젝트는 독립된 **웹 브라우저 환경**과 **VS Code 익스텐션 환경** 두 가지 방식으로 실행할 수 있습니다. (Node.js v18 이상 권장)

### 1. 웹 브라우저 단독 실행 (Web App)

```
cd web
npm ci
npm run dev -- --host 127.0.0.1
```

* 실행 후 `http://127.0.0.1:5173` 주소로 접속합니다.

### 2. VS Code 익스텐션 실행 (Extension Webview)

**1단계: 웹앱 빌드**

```
cd web
npm ci
npm run build
```

**2단계: 익스텐션 컴파일 및 실행**

```
cd ../extension
npm install
npm run compile
```

* VS Code에서 `extension` 폴더를 엽니다.
* `F5` 키를 눌러 디버그 모드(Extension Development Host)를 실행합니다.
* 새 창의 명령어 팔레트(Ctrl+Shift+P 또는 Cmd+Shift+P)에서 `SpecPilot: Open Dashboard` 명령어를 실행하면 에디터 패널 내에 UI가 나타납니다.
